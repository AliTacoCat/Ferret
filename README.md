# Ferret 
A semantic search engine for files. Finding the similarity in files instead of just ones that match the exact search.

## Why Ferret?
Most traditional search engines can only spot files that exactly match the words you type. Ferret, on the other hand, understands similar words and meaning behind words. 

## How is it done?

## Tech Stack
- **Language:** GO
- **Embeddings:** LM Studio, nomic-embed-text
- **Database:** PostgreSQL with pgvector extension

## Current status
- File walker with filtering
- AI embedding (768-dimensional vectors)
- PostgreSQL database
